#### Проектная работа "Mesto"

**Цель проекта:** создание интерактивной страницы на JavaScript, куда можно добавлять фотографии, удалять их и ставить лайки.

**Используемые стеки:** JavaScript, HTML, CSS, Webpack, Figma.

**В рамках проекта выполнены следующие задачи:**

- Создала инфраструктурное окружение с помощью Webpack;
- Разбила код на отдельные модули;
- Реализовала работу модальных окон, редактирования профиля, добавления карточки и превью фотографии, а также действие лайка на карточке;
- Разработала валидацию всех форм;
- Подключила интерфейс к API.
  
**Результат:** сайт с функциональностью на ванильном JS.
